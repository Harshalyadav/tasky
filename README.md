# tasky
Tasky is a simple to-do application built using **HTML**, **CSS**, and **JavaScript** to help users manage daily tasks efficiently.
The application provides a clean interface where users can add, view, update, and delete tasks with ease. By focusing on simplicity and performance, Tasky ensures a smooth experience without unnecessary complexity.

## Features
- Add new tasks quickly
- Mark tasks as completed
- Edit or delete existing tasks
- Clean and responsive user interface
- Lightweight and fast, with no external dependencies

## Tech Stack
- **HTML** – Structure of the application  
- **CSS** – Styling and layout  
- **JavaScript** – Application logic and interactivity  

## Purpose
Tasky is ideal for beginners learning front-end web development as well as users who want a minimal task management tool for everyday use.
